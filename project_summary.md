# AI Chatbot Development

## Tech Stack

- Python
- Generative AI
- NLP
- HTML, CSS, JavaScript

## Project Overview

Developed a ChatGPT-style conversational AI chatbot for intelligent query handling using Python, NLP-style intent matching, and optional Generative AI responses. The application includes a polished browser interface for natural language interaction, multi-chat history, project explanation, resume-ready output, and context-aware response generation.

## Key Highlights

- Built a responsive ChatGPT-style chatbot UI for real-time conversations.
- Added a sidebar for multiple local conversations.
- Implemented streaming assistant replies for a ChatGPT-like typing experience.
- Implemented conversation memory so the bot can answer context-based follow-up questions.
- Added an NLP-style local fallback for intent matching and topic-based responses.
- Added optional API-based generative response support using an environment variable.
- Added a runtime API key control for temporary local AI testing without saving secrets to files.
- Added prompt cards, copy controls, chat reset, delete, regenerate, and runtime AI status.
- Packaged the project as a runnable Python application with no required external dependencies.
